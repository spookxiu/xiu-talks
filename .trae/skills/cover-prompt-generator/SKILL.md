# 封面图描述生成

根据文章内容生成适合 AI 绘画的封面图描述。

## 功能

- 分析文章主题、情绪和核心意象
- 生成 50-100 字的封面图描述
- 提供风格、色调、元素建议

## 输出格式

```
封面图描述：[50-100字描述]

风格建议：[插画/摄影/抽象/写实等]
色调建议：[配色方案]
主体元素：[画面主要内容]
氛围：[情绪/氛围描述]
```

## 生成原则

- **避免文字**：AI生成图片中的文字效果差
- **突出意象**：提取文章核心意象或情绪
- **适合比例**：公众号封面 900x383 横幅比例
- **呼应主题**：与文章主题相关但不剧透

## 使用场景

- 用户说"生成封面" → 生成封面图描述
- 用户说"封面图" → 生成封面图描述
- 用户说"帮我画个封面" → 生成封面图描述

## 示例

**输入**：文章关于菜市场旅游

**输出**：
```
封面图描述：清晨的菜市场里，热气腾腾的早餐摊前围满了年轻人，摊位上摆满了各色地道美食，背景是熙熙攘攘的人群和老旧的市井建筑，阳光透过棚顶洒下温暖的光斑，画面充满生活气息和烟火味道。

风格建议：纪实摄影风格，略带暖色调滤镜
色调建议：暖黄色、橙红色为主，营造温馨氛围
主体元素：早餐摊、排队的人群、热气腾腾的食物、市井街道
氛围：烟火气、热闹、生活、温暖、治愈
```
