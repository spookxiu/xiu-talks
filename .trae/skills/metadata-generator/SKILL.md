# 文章元数据生成

生成文章摘要和多个版本的标题推荐。

## 功能

- 生成 34 字以内的一句话摘要
- 提供 3 个版本的标题推荐（A/B/C版）
- 优化标题以适应搜一搜流量

## 输出格式

```
## 摘要
"[34字以内的一句话摘要]"

## 标题推荐
- A版：[信息明确型标题]
- B版：[悬念吸引型标题]
- C版：[情感共鸣型标题]
```

## 生成原则

### 摘要
- 34 字以内（公众号列表显示限制）
- 一句话概括核心价值
- 制造点击欲望
- 避免"本文介绍了..."

### 标题
- **A版（信息明确型）**：适合干货内容，直接呈现主旨
- **B版（悬念吸引型）**：适合故事/观点内容，引发好奇
- **C版（情感共鸣型）**：适合随笔/感悟内容，触动情绪

### 搜一搜优化
- ✅ 呈现文章主旨、关键信息，不刻意隐瞒
- ✅ 简明扼要，避免过多修饰词
- ❌ 避免表意不明、标题党、震惊党
- ❌ 避免堆砌无意义符号和关键词

## 使用场景

- 用户说"生成摘要" → 生成摘要和标题
- 用户说"标题推荐" → 生成摘要和标题
- 用户说"帮我想个标题" → 生成摘要和标题

## 示例

**输入**：文章关于菜市场旅游

**输出**：
```
## 摘要
"当年轻人开始为了吃而旅行，他们其实是在寻找一种真实的连接。"

## 标题推荐
- A版：《你习以为常的厌倦，是别人羡慕的口水》
- B版：《坐高铁去沈阳吃盒饭，这届年轻人疯了吗？》
- C版：《菜市场的烟火气，治愈了多少疲惫的灵魂》
```
